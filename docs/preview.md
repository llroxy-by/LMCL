# 桌面预览版

`0.1.0-preview.3` 增加 M 系列 Mac 版，保留当前紧凑布局。头像仅作页面元素，应用图标仍用默认占位。

窗口默认 960×660，最小 820×560；启动时还会根据屏幕工作区缩小。长页面在内容区域滚动，侧栏、模式切换和底部状态栏保持可见。

## 开始使用

1. Windows 下载 x64 EXE 后直接运行；Mac 下载 ARM64 DMG，打开后将 LMCL 拖入 Applications。
2. 在“账户”里创建离线角色。
3. 在“下载”里获取版本列表，选择一个原版版本并下载。
4. 安装这个游戏版本需要的 Java。在“设置”中自动检测，或手动选择 `bin/java.exe`（Windows）／`Contents/Home/bin/java`（Mac）。下载完成的实例会显示需要的主版本。
5. 回到“我的游戏”，点击启动游戏。

也可导入包含 `versions` 文件夹的标准原版游戏目录。导入只记录位置，不复制或删除原文件。暂不支持加载器继承配置和旧版虚拟资源格式。

启动器配置和新下载的游戏实例存放在用户数据目录，可在设置页打开。Windows 通常为 `%APPDATA%/LMCL`，Mac 为 `~/Library/Application Support/LMCL`。移走启动器不会迁移存档。

## 已接入

- 原版版本目录、下载、官方文件哈希校验、取消下载；未完成的安装不加入实例列表。
- 离线角色、稳定的离线 UUID、Java 检测与手动选择、内存设置。
- 原版游戏目录导入、独立实例启动、运行状态和游戏日志。
- 普通／服务器模式切换、添加／移除接口、手动查询服务器目录。
- Windows 通过系统协议打开已安装的基岩版；Mac 隐藏这个入口。

Mac 版已用打包后的 LMCL、ARM64 Java 17 和 Minecraft 1.20.1 验证实际启动，完成图形渲染、音频初始化并正常退出。尚未验证存档游玩、多人连接及其他版本；Windows 版尚未完成真实游戏图形运行的人工验证。发现启动问题时，查看实例目录中的 `lmcl-game.log`。

## 构建验证

Windows 构建先运行自动测试和桌面冒烟测试，再生成单文件 EXE，随后直接运行该 EXE 做第二次冒烟测试。检查包括：界面和头像加载、离线角色保存、模式切换后账户保留、默认无服务器。构建会保存主页／下载页截图、报告和 SHA-256 校验文件。

本预览版没有 Windows 发布者签名。此说明仅描述签名状态，不代表可以忽略系统或安全软件报告的具体问题。

## M 系列 Mac

仅提供 ARM64 版本，最低 macOS 13，不提供 Intel 版。下载 DMG 后把 LMCL 拖入 Applications；ZIP 为相同应用的备用压缩包。

自动检测覆盖系统和用户的 JavaVirtualMachines 目录，以及 Homebrew 的 OpenJDK。只使用 ARM64 / AArch64 Java，同一环境不会重复列出。游戏要求 Java 17 就需要安装 ARM64 Java 17，不能只装最新 Java。

Mac 启动参数保留 `-XstartOnFirstThread`，只下载和使用当前架构的原生库。没有提供 ARM64 原生库的老版本会明确提示暂不支持，不会混用 Intel 库。可先使用 Minecraft 1.20.1 + ARM64 Java 17。

构建包含单元测试、源码和打包应用的界面冒烟测试、ARM64 架构检查与代码签名完整性检查。Mac 包使用临时签名（ad-hoc），未做 Developer ID 签名及苹果公证。若首次打开被系统拦截，可参考 [Apple 的打开应用说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”中检查提示。
